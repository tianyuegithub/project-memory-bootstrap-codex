# 治理协议入口

旧版CODEX首屏、先写每日日记、直接重写长期记忆和自动归档流程已退出受管项目的维护路径。当前字段、生命周期与写入权威唯一维护在[随包共享协议](../src/project_memory_bootstrap_codex/resources/shared-memory-protocol.md)。

治理判断分别依据用户有效决定、正式合同、实际实现和相应验证证据；不要用更新时间排序代替冲突判断。读取过旧摘要不算重新核验，文件年龄不自动使事实无效。

运行时只提供相关完整事实，预算不足提供展开入口。来源接收、语义判断、持久发布、检索缓存分别记录。受管项目的抑制或提交状态缺失时，不用旧正文/缓存伪造正常状态。

原始历史、原生工具记忆和已加载模型上下文不由共享库的逻辑删除自动清除；超出控制的副本和缺失证据必须明确说明。

# 定时维护与持续融合

共享程序本身不安装定时任务。字段与处理状态的唯一合同见[随包协议](../src/project_memory_bootstrap_codex/resources/shared-memory-protocol.md)。调度只负责唤醒，来源接收、候选、提交和抑制保存在项目持久状态，不能用一次运行结束时间跳过未处理内容。

现有 `templates/codex-automation-daily-memory-consolidation.toml` 是早期索引巡检参考，不是语义融合器，不直接复制到用户目录作为已启用任务。恢复或创建自动化使用宿主受支持工具，并核对已存在任务，避免重复调度。

空轮检查若本身先启动模型，就仍有模型调用成本。要做到无变化时不启动模型，必须先有实际验证过的确定性来源检查入口，再按待处理工作调用已授权的语义执行者，不能仅靠提示词宣称实现。

当前开发版本提供候选、提案、单文件提交和恢复CLI；自动来源发现、各宿主生命周期接入与持续语义运行器需按实际实现和实测结果报告。未实现或不可读取来源不能解释成无变化。

错误保留待处理范围；已经遗忘的内容不通过重放恢复。正常无变化保持安静，只在重要变化、失败、恢复或需要用户行动时通知。配置存在不等于一次真实增量闭环已通过。
